✨ Fitur Utama & Inovasi Interaksi

Mechanical Cartridge Loader (GSAP Choreography): Setiap proyek direpresentasikan sebagai kaset fisik 3D di rak mesin. Saat diklik, lengan gantry mekanis menarik kaset tersebut dan menancapkannya ke Central Core Slot.

GLSL Optical Data Shaders: Begitu kaset proyek menancap di Core, kabel serat optik di sisi kanan mesin menyala mengalirkan paket data menggunakan custom fragment shader menuju panel studi kasus.

X-Ray Blueprint Toggle (PHYSICAL_PBR $\leftrightarrow$ XRAY_SRS_BLUEPRINT): Satu tombol sakelar yang mengubah seluruh material mesin 3D menjadi glowing cyan wireframe, sekaligus mengalihkan isi artikel dari Eksekusi Produk ke Topologi Sistem, Skema Database, & Artefak PRD/SRS/QA.

Tactile Web Audio Synthesizer: Efek suara mekanis (hover click, servo motor dock, dan boot chord) disintesis secara real-time menggunakan Web Audio API (0 KB file audio eksternal).

Persistent WebGL Island: Memanfaatkan direktif transition:persist di Astro sehingga kanvas Three.js tidak pernah di-reload saat berpindah rute halaman.

Menjalankan Proyek Secara Lokal

Mode Prototipe Instan (Tanpa Build):
Buka file index.html langsung di browser modern untuk mencoba simulasi penuh 3D The Living System Core, lengkap dengan 4 kaset proyek, mode X-Ray Blueprint, Web Audio SFX, dan modal cetak CV.

Mode Pengembangan Astro (Production Stack):

# 1. Clone repositori
git clone https://github.com/nasrun-hidayattullah/nasrun-system-core.git
cd nasrun-system-core

# 2. Instal dependensi
npm install

# 3. Jalankan server pengembangan lokal (http://localhost:4321)
npm run dev

# 4. Build untuk produksi
npm run build
